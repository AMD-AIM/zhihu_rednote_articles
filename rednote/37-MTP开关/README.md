标题：A卡跑Qwen 27B比别人慢？先查这个开关

正文：
同一张卡跑同一个27B，别人一秒四五十个token，你才二十几个？
有位7900XTX的读者吐槽：「我用ollama一键部署…感觉比网友们慢挺多」。别急着换卡，先查MTP这个开关：开没开，开了几个。

💡 MTP是什么
这个27B的模型文件里多带了一层，专门往后猜几个字。
平时模型跑一遍出一个字；开了MTP，跑一遍能核对好几个，猜对的直接用，猜错的扔掉，答案水平不变。

📊 同一张R9700，开和不开
三种提示词各跑三次，取平均：
不开：每秒29个token
开MTP猜2个：写代码58个token，中文写作41个token，翻译47个token
写代码直接翻倍，中文也快了四成多。

🎚️ 猜几个，看你主要干什么
LM Studio 0.4.28和新版Ollama默认开着，分别猜3个和4个；llama.cpp默认不开。在哪看、在哪改，放在图里了。
我们在R9700上把猜1到4个都试了：写代码猜得越多越快，猜4个到了2.6倍；中文写作猜2到3个是1.4倍，猜4个反而掉到1.2倍。代码套路多，好猜；中文变化多，猜多了错得多，白算。
写代码多的设3到4，写中文多的设2到3。用Ollama写中文的，默认的4可以改小。拿不准就从2开始，AMD给R9700的建议也是2，锐龙AI Max+建议设4。

⚠️ 开了报错、没变快
报错或找不到选项的，先更新工具，再确认模型文件带MTP那一层。
没变快的，先确认真的开上了；开上了还嫌慢，再把猜的个数调小。llama.cpp日志里的猜中率偏低，就是猜多了。
