标题：Windows上用A卡跑AI，先装哪个？

正文：
Windows上AMD显卡跑AI，经常会遇到这种情况。

软件还没装上，ROCm、Vulkan、Linux已经先看了一圈。

其实先想清楚准备用AI干什么，后面该装什么就好选了。

💬 聊天、看文档

平时就是问问题、总结资料、读 PDF，门槛不高。

Lemonade、LM Studio这类工具都比较容易上手，模型也能直接下载。

不过先看一眼设备信息。如果显示的是CPU，虽然也能正常回复，但速度会慢不少。

🎨 生图、做视频

这类不是聊天框，是工作流。装完还要分别下模型和节点，不是开箱即用。

Windows环境下，建议先确认三件事：

✅ 显卡是否支持
✅ 驱动版本是否匹配
✅ 模型和节点有没有对应版本

另外，很多生图、视频模型占用更高，除了显存，内存和硬盘空间也要一起考虑。

💻 AI辅助写代码

反而比想象中省事。

本地模型跑起来后，通常会提供一个接口地址。把地址填进代码编辑器，就能直接调用本地模型。

⚙️ 自己写代码、训练模型

到这一步ROCm 和 PyTorch才开始变得重要。

不想换系统的话，还有 WSL2 这条路。原生 Windows 和 WSL2 支持的范围不一样，都按 AMD 的文档逐项核对，别照搬 Linux 教程。

Windows 上折腾半天没跑通，多半不是显卡不行，是还没想清楚要干什么，就先钻进了配置细节。先确定要干什么，再选工具，通常会省下不少时间。

你手里是哪张AMD显卡？现在主要拿它跑什么？

聊天、写代码、生图，还是做视频？👇
