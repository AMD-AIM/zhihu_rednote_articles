# AMD显卡能跑大模型吗

## 标题

**AMD显卡能跑大模型吗**（11 字，小红书上限 20 字）

## 正文

经常有人来问：这张卡能不能跑大模型？

跑包含推理和训练，能推理和能训练是两回事。

同一个 7B 模型，跑推理 5GB 显存就够。做全参数微调，80GB 起步。

差了十几倍。买之前不分清楚，很容易买了张跑得动、却训不动的卡。

💰 推理和训练是两回事（P2）

推理要装的东西少，模型权重加上聊天时攒下来的 KV Cache，就这两样。

训练不一样，权重、梯度、优化器状态、中间数据，四样都得往里塞。后面那三样加起来，常常比权重本身还大好几倍。

💻 只想在本地跑模型（P3）

这一档省心。4bit 量化之后，7B 约 5GB，14B 约 9GB，32B 约 20GB，70B 约 40GB。

16GB 这一档装 14B 以内没问题，32GB 的 R9700 还能再往上够一够。

软件这边省心，Ollama、LM Studio、llama.cpp 都有 ROCm 后端，Windows 上直接装。

🔧 想自己微调一个（P4）

全参数微调别想了，8B 就要 80GB 往上，个人机器扛不住。

大家实际走的是 LoRA 和 QLoRA。同样 8B，LoRA 约 28GB，QLoRA 能压到 12GB 上下，24GB 到 32GB 这一档就能开工。

⚡ 真要做训练（P5）

多卡、连着跑好几天，这是 Instinct MI 系列的活儿。

MI300X 是 192GB，MI355X 是 288GB，配 PyTorch 或 JAX，多卡通信走 RCCL。

⚠️ 这一步不少人栽过（P6）

Windows 上跑推理没问题，上面那几个工具都支持 Radeon。

但 PyTorch 训练、vLLM 和 SGLang 目前在 Linux 上更成熟。真要训练和微调，装个 Ubuntu 省事很多。

装的时候要填 gfx 代号，别填错，第 1 篇讲过怎么查。

显存数字为常见估算，实际取决于模型、上下文长度和推理框架；软硬件支持范围以 ROCm 7.14.0 兼容性矩阵为准。

你打算拿手里这张卡干哪件事？只跑推理，还是想动手微调一个？
