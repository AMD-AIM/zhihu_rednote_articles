# 选显卡做AI不再迷路｜A卡对标N卡哪一档

## 标题

A卡N卡型号对照表｜按档位对应

## 正文

AI 教程清一色按 N 卡写。

3090 起步、4090 更稳、5070 Ti 够用……

手里是 A 卡的人只能干瞪眼：我这张到底算哪一档？

这个问题被问太多次了，今天一次性对齐。

【01 先说清这张表是干嘛的】

按产品定位和价位段对，不是说两边性能一样。

同一档里，两家的架构、显存类型、软件生态都不同，真要选卡还得看你跑什么。这几张表只回答一件事：别人嘴里那张卡，A 卡这边大概是什么级别。

【02 游戏卡，看 P3】

RX 9070 XT 和 RX 9070，都是 16GB，对到 5070 Ti 和 5070 那一档。

RX 9060 XT 同样 16GB，对 5060 Ti。

上一代的 RX 7900 XTX 有 24GB，落在 4080 那一档。

【03 工作站卡，本地跑模型的重点看这段，P4】

Radeon AI PRO R9700，32GB，对 RTX PRO 4500 Blackwell 一档。

上一代的 Radeon PRO W7900，48GB，对 RTX 6000 Ada 一档。

这一档不用纠结别的，先问显存装不装得下。R9700 老被拿来跑 LLM，图的就是那 32GB。

【04 机房里那一档，看 P5】

MI355X 有 288GB HBM3E，对 B200 一档。

MI325X 是 256GB，对 H200。MI300X 是 192GB，对 H100。

再往前一代，MI250X 对 A100。

【05 这一档两家撞车了，看 P6】

128GB 统一内存，内存显存不再分家。

AMD 这边是 Ryzen AI Max+ 395，也就是 Strix Halo。那边是 DGX Spark，用的 GB10。

思路一样：小机器塞大内存，专门跑独显装不下的模型。

手里是哪张卡？型号留在下面，我帮你对。

型号与规格整理自两家公开的产品资料，以各自产品页为准。
