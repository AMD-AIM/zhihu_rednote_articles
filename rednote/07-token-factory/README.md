# 没本地显卡怎么跑DeepSeek？Token工厂来啦

## 标题

没本地显卡怎么跑DeepSeek？Token工厂来啦

## 正文

很多朋友首次接触大模型开发，流程往往是：

买显卡 → 装环境 → 配框架 → 部署服务 → 调模型

结果模型还没开始跑，环境先折腾了一天 😂

简单理解，云Token工厂有点像一个“大模型自助区”：

在页面里选择模型，创建访问凭证，再把模型接进自己的代码。

不用先准备AMD GPU，也不用先处理驱动、ROCm、PyTorch和推理服务。显卡可以慢慢研究，先让想法跑起来。

对于只想验证想法、做 Demo 或学 API 调用的人来说，少走很多弯路。

🏭 它是做什么的

云Token工厂部署在Radeon Cloud上，选哪个模型、怎么调用，一个页面就能看全。你可以查看模型ID、上下文长度、服务状态和参考价格，再决定用哪个。

目前还是Beta阶段，更适合：

✅熟悉模型调用流程

✅测试提示词

✅验证AI应用想法

✅制作Demo

✅比较不同模型的效果

🤖 目前有哪些模型？

目前已经能看到：

DeepSeek

GLM

Kimi

GPT-OSS

等模型入口。

后续模型列表也会持续更新。

🍽️ 三类服务怎么选

1️⃣ 想先试试看：用共享模型。

2️⃣ 想要独享资源：使用 Radeon Cloud Credits 部署 Dedicated Model。

3️⃣ 想体验合作伙伴模型：由第三方平台Fireworks AI提供服务的模型入口，按对应平台的规则申请和使用。

🔑 三步创建API Key

1️⃣ 登录 AMD Developer Program
2️⃣ 进入 AMD Developer Cloud
3️⃣ 打开 云Token工厂，选模型、创建并复制 API Key

还没注册过的话，可以翻翻主页之前那篇，注册流程已经整理过了。

共享模型目前支持 OpenAI-compatible API。手里有调用 OpenAI SDK 的代码，换掉模型 ID 和接口配置，就能直接拿来试。

🧮 1 积分能用多久？

每个账号每天有 1 积分通用 API 额度，北京时间刷新，当天没用完也不会攒到明天。

调用模型会扣多少，要看输入、输出和缓存价格。同样是 1 积分，选的模型不同、对话长短不同，能用的 Token 数也不一样。所以开聊前先瞄一眼模型卡，免得聊到兴头上突然余额不足。

⏰ 用之前留意这几点

模型和价格会不定期调整，打开页面看当时的状态就好。碰上大家都在用的时候，回复可能慢一点，不一定是代码写错了，过会儿再试试。

简单总结：

云Token工厂适合先把大模型接进代码，快速验证想法，再决定要不要搭建完整环境。
