标题：好奇大家用AMD显卡跑AI到底遇到什么问题啊？

## 正文

我们来自 AMD 个人工程师团队。

近期看到不少 A 卡上的真实问题：环境装好却不认卡、双卡输出一串没意义的字、同一模型下 ROCm 反而比 Vulkan 慢、再次生图时卡住。有些信息很完整，有些只差几个关键细节。

这篇想把大家在 AMD 显卡上部署模型时遇到的问题集中起来。信息写得越清楚，问题越容易被看懂和复现。

📋 问题模板

可以照下面的格式填写：

问题概述：
用一到三句话写清遇到了什么、期望怎样

GPU：
例如 AMD AI Max 395、Radeon RX 7900 XTX

ROCm 版本：
从 rocminfo 或 hipconfig 输出中查看

推理或训练框架：
例如 vLLM、llama.cpp、PyTorch、SGLang

框架版本：
例如 vLLM 0.6.3、llama.cpp b4123

后端：
ROCm、HIP、Vulkan 或 CPU

模型名称：
例如 Qwen3-8B、Geneformer、Llama-3-8B

量化方式：
FP16、BF16、INT8、AWQ、GGUF Q4_K_M，没量化就写“无”

复现步骤：
1.
2.

实际行为：

期望行为：

错误信息：
有就贴原文或截图

复现命令：
把启动命令整行贴出来
