手里还是6800、6700、6600的，这阵子是不是也被这句话扎到过：新版ROCm不支持6000系了。

🔍 名单上还剩谁

6000系只剩两张卡：W6800和V620。
6800、6900、6700、6600这些游戏卡，确实不在名单上。
但不在名单上，不等于跑不了。ROCm还有个社区版本，基本天天在更新，这几张游戏卡都有对应的安装包。只是它不算正式支持，踩了坑得自己多琢磨。

🏷️ 先查查自己的代号

社区版本的安装包按显卡代号分，装之前先对号入座：
6800、6900、W6800：gfx1030
6700、6750：gfx1031
6600：gfx1032
带XT的看前面数字就行，比如6800 XT就是gfx1030。
代号是ROCm认显卡用的名字，选错了包，装完也跑不起来。往前翻我们发过一张代号速查表。
